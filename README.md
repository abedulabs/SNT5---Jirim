# Makmal Digital Sains Tahun 5 — Jirim

- Simulator zarah bagi pepejal, cecair dan gas dengan pilihan keadaan serta pelaras suhu.
- Simulator ketumpatan: laras jisim dan isi padu, kira ketumpatan dan model terapung/tenggelam.
- Kuiz objektif ABCD: 21 soalan (21 markah).
- Pemerhatian: 5 soalan objektif (5 markah) dan 8 penyataan respons ringkas (15 markah).
- Slip pencapaian: jumlah 50 markah, peratus, gred A–F, komen dan cetak/Simpan PDF.

## GitHub Pages
1. Muat naik `index.html` ke root repositori.
2. Buka Settings → Pages.
3. Pilih Deploy from a branch, branch `main`, folder `/ (root)`, kemudian Save.
4. Buka URL GitHub Pages yang dipaparkan.

Semua fungsi berjalan dalam pelayar. Markah penyataan dikira secara automatik menggunakan kata kunci sebagai cadangan sahaja; guru perlu menyemak jawapan murid.
